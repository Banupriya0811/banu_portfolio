# Banupriya M — Full Stack Developer Portfolio

A modern, high-performance developer portfolio and content management studio built with React 19, TypeScript, TanStack Start & Router, and Tailwind CSS.

## 🚀 Overview

- **Hero & Profile Showcase**: High-impact introduction, interactive contact copy buttons, downloadable resume integration, and status indicators.
- **Interactive Projects Showcase**: Categorized project filter (Full Stack, AI/ML, System), live demo links, repository badges, and clean modal previews.
- **Technical Skills Matrix**: Visual categorizations for Frontend, Backend, Database Systems, and Cloud/DevOps tools.
- **Experience Timeline**: Career history covering production internship achievements and agile collaboration.
- **Education & Certifications**: Academic qualifications (B.Tech IT, CGPA 8.1) and industry-recognized certifications.
- **Admin Content Studio (`/admin`)**: Built-in content studio allowing full dynamic editing of your profile, projects, skills, and experience with live browser persistence and JSON backup/restore.

## 🛠️ Tech Stack

- **Framework**: React 19 + TanStack Start (SSR & Hybrid Rendering)
- **Routing**: TanStack Router (File-based routing)
- **Styling**: Tailwind CSS + Custom Design System with OKLCH color spaces
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Validation**: Zod
- **Notifications**: Sonner Toaster
- **Build Tool**: Vite

## 🔐 Admin Studio

To update projects, skills, bio, or links without touching code:
1. Navigate to `/admin` or click **Admin Studio** in the site footer.
2. Enter the default passcode: `admin123`
3. Edit any section in the tabbed interface.
4. Click **Save All Changes** to publish updates instantly.
5. You can also change the passcode in the Settings tab, or export a JSON backup of all your content.

## 💻 Local Development

Ensure you have Node.js 18+ installed:

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build
npm run build

# Preview production build locally
npm run preview
```
